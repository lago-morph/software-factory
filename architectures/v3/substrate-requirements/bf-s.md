## §1 Primitive list (buildability-confirmed)

BF-S requires 5 substrate primitives, all `designed-system` per Phase-3.5 sketches. (The brief assumes universal substrate primitives — sandbox, trajectory capture, cost ceilings, watchdog tiers — land in Phase 4 as cross-cutting commodity primitives per [BF-S §1.1 closing paragraph](../tracks/brownfield-substrate-first.md); they are not re-listed here.)

- **[P-22 — Polyglot codebase index](../primitives/P-22-polyglot-codebase-index.md) (S-1).** Incrementally maintained, queryable index of symbols, definitions, references, call graph, module boundaries, and per-language type information. Returns *slices* sized to caller's context budget — the F21 mitigation only works if the contract is "give me only what's relevant." Construction: tree-sitter (universal AST) + per-language LSP federation; Sourcegraph/SCIP at fleet scale; Glean at Meta-scale. Verdict: `designed-system`.
- **[P-23 — Dependency-and-impact graph](../primitives/P-23-dependency-impact-graph.md) (S-2).** Per-symbol forward / reverse closure + per-change impact ranking, cross-language where schema-mediated bindings exist. Construction: Glean (Datalog) + Stack Graphs cross-language resolver; CodeQL alternative; tree-sitter + Neo4j fallback. Verdict: `designed-system`.
- **[P-07 — Telemetry ingestor (per-role read filters)](../primitives/cluster-C2.md#p-07-telemetry-ingestor-per-role-read-filters) (S-3).** OpenTelemetry-shaped telemetry pipeline with ABAC-mediated per-role partitioning of reads (builder cannot read holdout slice; V&V can). Construction: OpenTelemetry Collector + OPA-policy SQL-rewrite layer in front of the observability backend, optionally wrapped by P-25 perimeter for the BF-S architectural framing. Verdict: `designed-system` (escalated from commodity at sketch time per [cluster-C2 § P-07](../primitives/cluster-C2.md)).
- **[P-24 — Change-history / attribution store](../primitives/P-24-attribution-store.md) (S-4).** Append-only, signed per-symbol attribution. Construction: `git verify-commit` (mandatory signed commits) + `git blame --line-porcelain` joined to P-22's symbol-range index + Sigstore/cosign for factory-authored events + Postgres `attribution_events` projection. Hard P-22 dependency for per-symbol granularity. Verdict: `designed-system`.
- **[P-25 — CaMeL-class typed perimeter](../primitives/P-25-camel-perimeter.md) (S-5).** Capability-typed boundary; Privileged/Quarantined LLM split; typed-interpreter pattern; production-scissors default off; F44 substrate-default closure. Construction: released CaMeL reference implementation (`google-research/camel-prompt-injection`) + OPA inside (policy) + eBPF below (defence-in-depth). Verdict: `designed-system`.

Per the [Phase-3.5.5 BF-S forward action](../candidate-registry.md#bf-s--brownfield-substrate-first-1), the B7 ROBUST claim is rephrased accordingly; residual leakage is accepted-open and registered as a Phase-8 lean-eval candidate (how much can an adversary exfiltrate via the count-and-aggregate side channel under realistic adversarial-budget constraints?). - **A partial-RG flag on P-25 (utility-tax calibration).** Per the [P-25 sketch §Research-grade-uncertainty flag](../primitives/P-25-camel-perimeter.md#research-grade-uncertainty-flag): `partial — utility-tax calibration only`. BF-S's choice on this partial-RG sub-component: **(b) accept-as-RG on the calibration sub-component**, deferred to per-deployment measurement. The substrate must expose a configurable per-work-unit-class bypass with the bypass itself substrate-logged (F53-resistant). No bounded sub-track is owed at Phase 4 — calibration is per-deployment work, not substrate-layer work.
