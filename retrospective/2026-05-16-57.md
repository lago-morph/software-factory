User triggered the `research-pipeline` skill with *"drain, use subagents as much as makes sense."* Phase-0 inventory of `research/manual/` returned **12 files**: 5 RE/SE primary methodology PDFs/MHTML (EARS, INCOSE TP-2020-002-06, INCOSE GtWR v4 summary sheet, INCOSE *Complexity Primer*, AFIS *Requirements and Architecture within Modelling Context*); 3 academic LLM+RE papers (Norheim et al. *Design Science* 2024, Yang et al. arXiv:2505.13360v3, Larbi et al. arXiv:2507.20439v1); 2 Kiro vendor blog posts (deep-spec-analysis + from-copilots-to-coworkers); 1 Cherny YouTube transcript that turned out to be a duplicate of the already-drained `reference-only/lenny-podcast-transcripts/cherny-head-of-claude-code-full.txt` (different transcription of same 90-min source; deleted without drain).

Pre-flight binary→text conversion: installed `html2text` via `pip3` and ran a Python loop using `email.message_from_bytes` to extract HTML bodies from each MHTML file as `.txt` sidecars. This let the subagents read plain text rather than wrestle with MIME chrome — saved tokens, eliminated a class of parsing failure.

They are really important."* This was a genuine drain-completeness bug — the html2text conversion in Phase 1 had silently stripped image content, and several load-bearing operational details lived only in those figures.

Recovery sequence:

1. **Restore deleted file** — `git show HEAD~1:"research/manual/Requirements analysis... .mhtml" > /tmp/kiro-deep-spec.mhtml`. Clean and minimal.
2. **Extract images** — Python script walking the MHTML via `email.walk()`, filtering `image/*` content types, decoding `part.get_payload(decode=True)`, saving each with a sha1-derived filename. 12 images total: 6 substantive figures + 5 author headshots + 1 wordmark.
3. **View figures** — six parallel `Read` calls on the PNG paths. **Discovery: the Read tool natively renders PNG images as vision inputs.** No OCR setup, no vision-API wrangling.
4. **Synthesize new material** — six concrete operational details that were *only* in the figures:

   - per-stage toolchain attribution (Z3 named explicitly; not generic SMT)

   - three named SMT finding types (direct contradiction / case-split contradiction / completeness gap) with minimal scopes
   - Tier-1 abductive-refinement classification vocabulary (Test Blocker / State Definition / Precision Gap) bound to NEW vs AMENDED criteria
5. **Fold into report 12 §2.5** as a clearly-demarcated "Image-anchored details" sub-block; updated revision-notes block at top + the sources-reviewed row for the deep-spec URL.
6. **Cleanup** — deleted `/tmp/kiro-deep-spec.mhtml` and `/tmp/kiro-images/`; nothing extra committed.
