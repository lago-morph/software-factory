# `reconstituted-sources/` — source dedup worksheet

One row per **canonical source** (one row per URL group). 154 rows covering all 218 source files. Sorted alphabetically by title.

## Columns

- **#** — row number
- **Title** — extracted from the file (HTML `<title>`/`<h1>`, MHTML `Subject:`, MD `# heading`, etc.)
- **URL** — canonical
- **Files (status, size)** — every file in this group, with byte size and one of these status tags:
  - `[primary]` — most informative version, usually most-original format (`.mhtml` > `.html` > `.md` > `.txt`)
  - `[text-extract]` — the markdown/text companion of an html (deliberate paired representation, not a duplicate)
  - `[raw-source]` — the html/mhtml that a text-extract was derived from
  - `[partial: <reason>]` — clearly missing content (truncated transcript, single chapter, etc.)
  - `[incomplete: 404 stub | paywall | JS-rendered shell]` — error/empty content
  - `[duplicate]` — same content as primary, redundant
  - `[different-capture]` — independently captured, different format
- **Images** — for `.mhtml` from the manual lineage, image utility was reviewed in the earlier indexing pass:
  - `N (reviewed, useful — kept as .mhtml)` — image count from manual-manifest.json
  - `N (reviewed, NOT useful — converted to .txt)`
  - `present (fetched, not reviewed)` — fetched HTML; images linked, never manually reviewed
  - `present in PDF` / `none` / `unknown`
- **Bucket** — empty, for you to mark verdicts (e.g. ✅ keep / 🗑 delete dupes / ➕ merge / ❓ review)

## Bucketing legend

- ✅ — clearly no duplication (keep all files as distinct representations)
- 🗑 — duplicate, delete lesser version(s)
- ➕ — merge: keep canonical, append unique content from others
- ❓ — needs manual review
