- Maintain a **per-component coverage ledger** in [`STATUS.md`](./STATUS.md) on four axes `{built, reviewed, incorporated, integrated}`. The run is not done until every built component is green on all four.
- Checkpoint **commit + push after every wave**; keep one PR current; end with `run-summary.md` (repo root) + a refreshed [`HANDOFF.md`](./HANDOFF.md) + a [`self-retrospective`](../../../.claude/skills/self-retrospective/SKILL.md).
