# agent instruction

**Charter-first navigation on a project framing pivot.** When a session pivots the project's framing or working model, capture the corrected model in a charter document and point the entry/navigation doc at it as "read this first for the feel" -- so a future agent absorbs the current framing before the older design docs that predate the pivot.

*Grounded in: adding factory-discovery-charter.md and pointing AGENT-ENTRY section 2 at it as read-first.*

# justification

This session reframed the entire approach to using the v4 factory (co-implementation, prototype-for-discovery, trust map, play-menu-of-cards, fun-first). That model lives nowhere in the older design corpus, which a fresh agent would otherwise read first and absorb the superseded framing from. The operator explicitly asked to "record the essence so future agents can get a feel for what we're doing." A charter document plus a single navigation line ("read this for the feel before the design docs") gives every future session the current mental model in one hop. The marginal cost is one doc and one edited navigation bullet; the cost of omitting it is every future agent re-deriving the framing from scratch, or worse, inheriting the pre-pivot framing from the design docs and acting on it.
