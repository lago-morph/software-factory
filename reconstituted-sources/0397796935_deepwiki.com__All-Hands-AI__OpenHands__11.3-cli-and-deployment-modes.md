## Overview

The GitHub Actions CI/CD pipeline orchestrates automated testing, building, and publishing of OpenHands Docker images. The pipeline executes five primary workflows:

  1. **`ghcr-build.yml`** \- Builds and publishes Docker images (app, runtime, enterprise)
  2. **`lint.yml`** \- Executes linters on Python and TypeScript code
  3. **`fe-unit-tests.yml`** \- Runs frontend test suite
  4. **`lint-fix.yml`** \- Auto-fixes linting issues when triggered
  5. **`stale.yml`** \- Manages stale issues and PRs



Related documentation: Local development workflow (page 11.1), Docker image building strategy (page 11.2), pre-commit hooks (page 11.4).

Title: Runtime Image Build Pipeline


The `runtime_build.py` module invokes `prep_build_folder()` which:

  1. Copies `openhands/` source to `containers/runtime/code/openhands/`
  2. Copies `skills/` directory to `containers/runtime/code/skills/`

  4. Generates `Dockerfile` from Jinja2 template `Dockerfile.j2`



The `build.sh --dry` command outputs `docker-build-dry.json`:


Tag naming follows the pattern:

  * `oh_v{version}_{lock_hash}_{source_hash}` (source tag)
  * `oh_v{version}_{lock_hash}` (lock tag)
  * `oh_v{version}_{versioned_tag}` (versioned tag, SCRATCH builds only)



Where:

  * `lock_hash` = `get_hash_for_lock_files()` from `pyproject.toml` \+ `poetry.lock`
  * `source_hash` = `get_hash_for_source_files()` from `openhands/` directory
  * `versioned_tag` = `get_tag_for_versioned_image()` from base image name

## Conditional Execution

Jobs use `if` conditions for conditional execution:

Job| Condition| Purpose  
---|---|---  
`ghcr_build_app`| `!(github.event_name == 'push' && startsWith(github.ref, 'refs/tags/ext-v'))`| Skip for external extension tags  
`ghcr_build_enterprise`| `github.event.pull_request.head.repo.fork != true`| Skip for forked PRs  
`enterprise-preview`| `github.event_name == 'pull_request' && contains(github.event.pull_request.labels.*.name, 'deploy')`| Only when PR has `deploy` label  
`update_pr_description`| `github.event_name == 'pull_request' && !github.event.pull_request.head.repo.fork && github.actor != 'dependabot[bot]'`| Skip for forks and Dependabot  
`lint-fix-frontend`| `github.event.label.name == 'lint-fix'`| Only when PR labeled `lint-fix`  
`stale`| `github.repository == 'OpenHands/OpenHands'`| Only in main repository (not forks)
