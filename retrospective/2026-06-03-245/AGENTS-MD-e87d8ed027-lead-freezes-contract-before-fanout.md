# agent instruction

**Lead freezes the shared cross-component contract as a ledger decision before the dependent fanout.** When a parallel authoring fanout shares one cross-component contract (a record schema, an interface, a payload), the lead agent MUST design and freeze that contract as a numbered ledger decision FIRST, then ship its verbatim text in every dependent subagent's brief. The keystone-builder-first pass then becomes a verification step (does the contract fit the owning component?), not the contract-discovery step. Do not let each subagent infer the shared contract independently.

*Grounded in: D-43 frozen before the C32 keystone + the C52/C53/C30/C08/C34 wave; the seam adversary found zero drift on the lead-frozen records.*

# justification

The triangle-eval implementation plan (HANDOFF §0★.4) said "C32 first because it defines the diagnosis contract" — i.e. the contract would be *discovered* by authoring the keystone, then the dependent wave pre-briefed from it. Instead the lead designed the `DiagnosisRecord` schema up front and froze it as ledger decision **D-43**, then shipped its verbatim field table to all six subagents (the C32 builder *and* the five dependent builders). The payoff was measured: the opus seam adversary field-level-verified `ScoreRecord` and `DiagnosisRecord` against every consumer (C33/C34/C46 for the former; C52/C53/C34 for the latter) and found **zero drift** — every consumer used the exact field names, types, and enum value-sets. The contrast in the same session is stark: the one contract that was *not* lead-frozen — the new correction-request payload, which each of C52/C08/C30 designed independently for its own side — drifted on three axes (traceability key, rationale field name, a missing origin field) and required a whole integration pass (D-44/D-45) to reconcile. The marginal cost of lead-freezing is one ledger entry written before dispatch; the cost of not doing it is a full adversary-find-plus-integrator-pass cycle per shared contract. Freeze the contract the subagents share; let them discover only what they own.
