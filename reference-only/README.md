## Organisation

As of 2026-05-16, sources are grouped into **subject-matter** subdirectories (interim — see `reorg-plan.md`). Categories were chosen by the topic the source primarily speaks to, not by medium. The first-pass subject-matter taxonomy here will be refined in a later step once additional sources are restored from git history.
