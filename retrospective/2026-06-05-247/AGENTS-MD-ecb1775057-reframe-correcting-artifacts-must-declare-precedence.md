# agent instruction

**Reframe-correcting artifacts must declare precedence.** When a later artifact corrects the framing of an earlier one, state the precedence explicitly in the new artifact (for example, "this charter wins on framing where older docs disagree") and add a superseding pointer; never leave a corrected framing to coexist silently with the stale one.

*Grounded in: this session's charter explicitly superseding the earlier mis-framed next-steps report.*

# justification

Mid-session the operator corrected a foundational framing (the factory is a co-implemented prototype-for-discovery across a portfolio, not a march to a finished factory with agent-os as the sole workload run like a production line). Several already-merged-to-branch artifacts still carried the old framing. Without an explicit precedence declaration, a future reader hits two artifacts that disagree and cannot tell which is current — the exact confusion that wastes a session re-deriving "what do we actually believe now?" The fix is one sentence in the new artifact plus a pointer; the cost of omitting it is a future agent silently building on superseded framing. The charter added "where older artifacts disagree on framing, this charter wins" and AGENT-ENTRY was pointed at it — a near-zero marginal cost that makes the corpus self-disambiguating.
