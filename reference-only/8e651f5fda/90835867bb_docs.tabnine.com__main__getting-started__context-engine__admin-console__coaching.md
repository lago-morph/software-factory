# Coaching Guidelines

circle-info

 _This feature is currently in closed beta β_

### 

hashtag

Define Your Coaching Guidelines

As an Admin (or team lead for a specific team, as of [**5.27.0**](/main/administering-tabnine/release-notes#v5.27.0)), navigate to **Personalization** , then **Coaching Guidelines**.

You’ll see two options:

EITHER Import your own guidelines via CSV (a downloadable template is available). 

OR Use the default guidelines provided by Tabnine.

If you choose to import your own:

  * Only the Language and Description fields are required.

  * Other fields (e.g., tags, good/bad code examples) can be auto-generated by Tabnine.
