# `reconstituted-sources/` — INDEX

**Purpose:** archive of every ingested source ever used in this research project, recovered from git history (including deleted-branch blobs that survived in the pack) plus the surviving `research/manual/` set. One row per file. Companion archive: `reference-only/` (canonical pre-saved sources — not duplicated here).

**Sort order:** rows sorted alphabetically (case-insensitive) by filename.

**File-type legend:**
- `[hash]_<host>__<path>.html` / `.md` — fetched via the issue-N URL-fetch GitHub Actions workflow. HTML is the raw browser-rendered fetch; MD is the markdown-extracted body.
- `*.mhtml` — manual browser save (preserves all assets inline).
- `*.txt` — text capture (manual paste or html2text export).
- `*.pdf` — PDF download.

**Stats:** 218 source files. Recovered via `git rev-list --all --objects` lookups across reachable and unreachable git objects (branches deleted post-merge still have blobs in the pack). 6 files dedup'd against `reference-only/` canonical versions. Companion files in this directory: `PLAN.md` (recovery plan), `new-index.md` (preserved preliminary index of the 71-source manual drop), `manual-manifest.json` (URL+title for the 49-source manual set).

**Recovery integrity note:** during the recovery pass an `awk` bug caused ~105 files to be initialized with wrong content (a too-permissive path-suffix match selected blobs from unrelated paths). The bug was fixed and those files were re-recovered with correct content; the INDEX entries you see below describe the corrected content.
